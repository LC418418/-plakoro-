# 八館改版計劃

把「4 章隨機道館」改成「8 章順序道館 + 敵人屬性集中」嘅完整交接文件。

**點用呢份文件**：每個階段開一個**新嘅 Claude session**（唔好接住舊嘅），
第一句就打「睇 `docs/八館改版計劃.md`，做階段 X」。
新 session 平均每次呼叫嘅 context 少一半以上，同樣工作量平大約一半。

## 一、而家個遊戲係點運作

唔使識 code 都睇得明嘅版本：

- 一局有 **4 章**。每章係一張 **10 層**嘅地圖，由第 1 層行到第 10 層。
- 第 10 層就係**道館主**。打贏拎徽章，跳去下一章。
- 遊戲入面有 **8 個道館**，但每局只會**隨機抽 4 個**出嚟，順序都係亂咁排。
- 打完 4 章 → **四天王**連戰 4 場 → **冠軍**。
- 中途撞到嘅敵人（雜魚、精英）係喺全 151 隻入面**完全隨機抽**嘅。

最後嗰點就係你想改嘅核心：**你而家喺火焰道館嗰章，一樣會撞到水系、草系、雷系**。
所以「用屬性剋制去過關」呢一層策略根本用唔到 —— 你冇得預先準備。

## 二、改完之後會變成點

- 一局有 **8 章**，順序固定：小剛 → 小霞 → 馬志士 → 莉佳 → 阿桔 → 娜姿 → 夏伯 → 坂木
  （同原著一樣）。
- 每章嘅地圖縮短到 **5-6 層**（而家係 10 層）。
- 每章**大約七成敵人係嗰個道館嘅屬性**。即係打火焰道館嗰章，成章都係火系，
  你可以特登留低水系隊友、砌水系骰。
- 每章拎到嘅遺物由 2-3 件減到 **1-2 件**（因為章數多咗一倍，唔減就會爆）。

## 三、⚠ 四件事要你先決定

呢四樣唔決定就做唔落，而且全部都係我掃 code 之後先發現嘅，唔係設計偏好問題。

### 決定 1：雷屬性得 6 隻寶可夢，唔夠開一章

我數咗全部非神獸寶可夢嘅屬性分佈：

| 屬性 | 隻數 |
|---|---|
| 水 | 31 |
| 草 | 24 |
| 闘 | 19 |
| 悪 | 17 |
| 空 | 12 |
| 無 | 12 |
| 炎 | 11 |
| 超 | 11 |
| **雷** | **6** |
| 鋼 | 2 |

八個道館嘅屬性係：闘、水、**雷**、草、悪、超、炎、闘。

問題：雷電道館嗰章要打 5-6 場，七成係雷系即係 4 場，但**得 6 隻雷系可以抽**
—— 你會連續撞到同一隻皮卡丘三次。炎同超（11 隻）都偏緊張。

**選項**

- **A（建議）**：集中度按池大細調整 —— 水／草／闘 用 70%，炎／超 用 55%，雷 用 40%。
  好處係唔使改任何寶可夢資料，壞處係雷電道館嘅「屬性感」冇其他館咁強。
- **B**：雷電道館嗰章開放埋神獸同進化型落去雷系池。池大咗，但雷系神獸好強，
  要另外調嗰章嘅難度。
- **C**：接受重複。撞三次皮卡丘唔一定係壞事 —— 呢個係「雷電道館」嘅特色。

### 決定 2：兩個道館都係「闘」屬性

**小剛**（原著岩石道館）同**坂木**（原著地面道館）喺呢個遊戲入面**都標咗做「闘」**,
因為呢個遊戲根本冇「岩石」同「地面」呢兩個屬性。

而家隨機抽 4 個道館，兩個撞埋嘅機會唔高，冇人為意。
但改成八個順序全部要打之後，**第 1 章同第 8 章會用同一種敵人**，
而佢哋分別係最容易同最難嗰章，感覺會好怪。

**選項**

- **A（建議）**：坂木改做「悪」屬性（17 隻，池夠大），符合佢火箭隊老大嘅形象。
- **B**：小剛改做「無」屬性（12 隻），第 1 章用最普通嘅敵人做教學章。
- **C**：兩個都保留「闘」，接受重複。

### 決定 3：而家玩緊嘅存檔點算

八章嘅存檔同四章嘅**唔夾** —— 存檔入面記住咗「呢局係邊 4 個道館」，
讀返出嚟會對唔上。你而家有同事玩緊，所以要決定點處理。

**選項**

- **A（建議）**：出新版嗰陣**清走所有進行中嘅存檔**，同大家講一聲。
  **名人堂嘅隊伍唔會受影響**（佢哋存喺另一個地方），排行榜紀錄都照留。
  損失就係大家手上未打完嗰局要重新開始。最平、最穩陣。
- **B**：寫兩套邏輯，舊存檔照四章規則行到完，新開嘅局先行八章。
  貴好多（等於同時維護兩個版本嘅遊戲），亦都最容易出 bug。

### 決定 4：一局會變**長**，唔係短

你講「每個道館嘅關卡數量可以減少」，呢個做得到。但總數係加咗：

| | 而家 | 改完 |
|---|---|---|
| 章數 | 4 | 8 |
| 每章最少場數 | 6 | 4 |
| **一局最少打幾多場** | **24** | **32** |

即係一局長咗大約**三分一**。呢個係「八個道館全部要打」跟住嚟嘅必然結果。

**選項**

- **A（建議）**：接受變長。八章嘅節奏感本身就係賣點，而且每章短咗，
  中途放低再返嚟容易好多。
- **B**：每章縮到 4 層（最少 3 場）。總長度同而家差唔多，
  但每章就得 2 場雜魚，「屬性集中」嘅感覺會好薄 —— 兩場打完就過咗，
  未夠時間逼你調整隊伍。呢個做法會抵消咗成個改版嘅意義。

## 五、關鍵建議：TIER 由「數字表」改成「一條公式」

呢個係成個改版入面**最值錢嘅一步**，值得單獨講。

**而家係點**：敵人嘅強度寫死喺一個表度，每一章一格數字：

```
gym:   { hp:[143,211,196,220], nm:[1.482, 2.28, 2.50, 2.90] }
              ↑    ↑    ↑    ↑
            第1章 第2章 第3章 第4章
```

四章嘅時候勉強調得掂。**八章嘅話呢啲陣列會變成 8 格**，五個 tier 加埋
就係 80 個數字要人手調 —— 每次改一個都要重新跑模擬器，做唔完。

**建議改成**：只寫**起點**同**終點**，中間用公式自動計：

```
gym: { hp0:143, hp8:900, nm0:1.48, nm8:3.20 }
第 a 章嘅強度 = 起點 × (終點 ÷ 起點) ^ (a ÷ 7)
```

咁每個 tier 得 **4 個旋鈕**（起點血、終點血、起點傷、終點傷），
五個 tier 加埋 20 個，而實際上只需要調 gym 同 mob 兩個，即係 **8 個旋鈕**。
調八章反而**易過**而家調四章。

**額外好處**：難度曲線會變順滑。而家嗰個表因為係人手逐格填，
第 2 章到第 3 章嘅血量係 `211 → 196`（**跌咗**），
係之前調嘅時候為咗遷就「第 3 章開始道館主帶 3 隻」而屈出嚟嘅。
用公式就唔會有呢種怪位。

**做法建議**：直接寫**成隊道館主嘅總血量**，再除以嗰章帶幾多隻。
咁「帶 2 隻定 3 隻」就唔會再搞亂條曲線。

## 六、四個陷阱（呢次調平衡撞返嚟嘅，唔好再撞）

### 1. 郁一章會連帶影響之後嗰幾章

前面難咗，行得到後面嘅隊伍**本身就強啲**，所以後面反而會顯得易咗。
實測：第 2 章由 46% 拉落 36%，第 4 章就自己彈上 48%。

**所以**：要一次過睇齊所有章數，唔好逐章追。八章嘅話呢個效應會更明顯。

### 2. 後面幾章對數值極度敏感

行到後面嘅係最強嗰幾 % 隊伍，人數本身好薄，加少少就冧一大片。
實測（魔鬼難度）：血量倍率由 0.93 加到 1.20，第 3 章由 63% **直跌到 15%**。
即係 0.05 嘅級距抵得上十幾點通關率。

**所以**：一次行 0.05，唔好跳 0.2。我今次跳咗 0.2，白費咗一轉。

### 3. 模擬器跑幾多局係**完全唔影響成本**

跑 3000 局同跑 8000 局，返嚟都係同一舊細細嘅 JSON，AI 用量一模一樣，
分別淨係部電腦行耐幾十秒。

**所以**：一次 sweep 塞 8 組設定去試，唔好一次試 3 組。
局數開 3000 起跳。呢個係純賺，冇代價。

### 4. 有咗遺物上限之後，「遺物/章」呢個數字要識睇

`measure.mjs` 印嘅「遺物/章」係**淨增長**。遺物上限係 8 件，
多數局第 2-3 章就滿咗，所以後面嘅數字自然會跌近零 ——
**唔係代表冇遺物拎**，係代表之後每一件都要換走一件。
