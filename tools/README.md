# 爬塔平衡模擬器

呢個資料夾**唔屬於遊戲本體**。`index.html` 唔會載入呢度任何嘢，玩家永遠見唔到。
純粹係開發時用嚟調數值嘅工具。

## 做咩用

改爬塔難度嘅時候，靠自己試玩幾局係量唔準嘅 —— 通關率 50% 定 65%，
玩十局都分唔出。呢個模擬器用**遊戲本身嘅戰鬥引擎**跑成千局，直接量到真實通關率。

模擬嘅係一個「識玩但唔會神操作」嘅玩家：

- 每回合揀期望值最高嗰招（命中率 × 傷害，打弱點加權）
- 上場嗰隻血少過兩成、而有健康隊友就換人
- 打低對手一隻之後有**免費換人**機會：上場嗰隻血少過六成就換返隻精神啲嘅
- 獎勵優先攞遺物 > 招式強化 > 新招 > 骰晶片
- 遺物滿咗（8 件）就掉最冇稀有度嗰件，新嗰件唔夠好就索性唔換
- 進化唔到嘅寶可夢夠場數就特訓，血同傷害隨機揀一樣
- 四天王之間有隊友低過七成血、又買得起就買補給
- 商店有錢就買，血少就買傷藥（道具排喺遺物同招式後面，唔會食晒啲錢）
- 道具：升級器即刻用、出戰有人倒咗就用復活藥丸、平均血低過 55% 先用厲害傷藥
- 走地圖時隨機揀下一個節點

所以出嚟嘅數字係一個**中間水平**：識用屬性剋制、換人時機同骰子工房配骰嘅人會高過呢啲數，
求其亂打會低啲。

## 點跑

第一次要裝 Playwright（只需做一次）：

```bash
cd tools && npm install
```

### 量度而家嘅通關率

```bash
node tools/measure.mjs            # 1200 局，困難
node tools/measure.mjs 1400 0     # 1400 局，困難
node tools/measure.mjs 900 1      # 900 局，魔鬼
```

輸出：

```
章節   行到    打低    通關率   遺物/章
第 1 館   6000   3970     66%    1.63
第 2 館   3970   2503     63%    1.62
第 3 館   2503   1492     60%    1.55
第 4 館   1492    805     54%    1
第 5 館    805    415     52%    0.25
第 6 館    415    225     54%    0.03
第 7 館    225    115     51%    0
第 8 館    115     52     45%    0

四天王     52     10     19%    （4 連戰 + 冠軍）

8 館全通：1%　真・全通（連冠軍）：0%

四天王入場：2245.5 金・8 件遺物・平均買 2.9 次補給
陣亡位置：天王1 0　天王2 1　天王3 0　天王4 7　冠軍 34
```

「通關率」＝ 行到嗰章嘅局數入面，成功打低道館主嘅比率。
途中俾雜魚打死都當冇通關（因為一樣打唔到道館主）。

「遺物/章」係**淨增長**。遺物有上限（`RELIC_MAX`，而家 8 件），
多數局第 4-5 章就已經滿曬，所以之後嘅數字自然會跌近零 ——
唔係代表冇遺物拎，係代表之後每一件都要換走一件。

「8 館全通 1%」睇落好低，但呢個係八章制嘅算術結果，唔係太難：
每章 55% 嘅話，連過八關就係 0.55⁸ ≈ 0.8%，同舊嗰個四章版差唔多。

「陣亡位置」睇得出四天王段落邊度先係真牆。而家係冠軍。

### 試唔同數值（唔使改 index.html）

```bash
N=800 node tools/sweep.mjs '[
  {"dmg":{"all":1.0}},
  {"dmg":{"all":1.0},"dmgAct":[1,1,1,1.15]},
  {"dmg":{"all":1.1},"hp":{"all":1.05}}
]'
```

倍率 `1.0` 就係 `index.html` 而家嘅數值。可以調嘅嘢：

| 欄位 | 意思 |
|---|---|
| `curve` | **主力旋鈕**：敵人強度曲線嘅端點，`{"gym":{"hp1":1100}}`。見下面 |
| `actTune` | **主力旋鈕**：逐章微調，`{"hp":[…8 格…],"dmg":[…8 格…]}` |
| `dmg` | 敵人傷害倍率，`{all:1.2}` 或者逐個 tier `{mob:1.1, gym:1.3}` |
| `hp` | 敵人血量倍率，寫法同上 |
| `dmgAct` | 再按章節乘一次，`[第1章 … 第8章]`（同 `actTune.dmg` 重疊，試嘢先用） |
| `hpAct` | 同上，血量版 |
| `post` | 每場勝利回幾多血（最大 HP 百分比） |
| `rest` | 篝火回血 |
| `badgeHeal` / `badgeHp` | 拎徽章時回血 / 加最大 HP |
| `diff0` | 覆蓋「困難」難度嘅倍率，例如 `{"heal":0.9}` |
| `diff1` | 覆蓋「魔鬼」難度。`hp` / `dmg` 可以寫 8 格陣列逐章唔同 |
| `set` | 直接寫死某個 tier 嘅陣列，用嚟單獨郁一章：`{"gym":{"nm":[…],"hp":[…]}}` |

### 兩個主力旋鈕（八館改版之後就係靠呢兩個）

`index.html` 入面**冇咗**逐章嘅數字表。敵人強度而家係一條公式：

```
第 a 章 = 起點 × (終點 ÷ 起點) ^ (a ÷ 7)        再乘 ACT_TUNE[a]
```

- `TIER` 每個 tier 得 4 個數：`hp0` `hp1` `nm0` `nm1`（第 1 章同第 8 章）。
  改條曲線嘅**大方向**（成局係咪一路難上去）就郁呢啲。
- `ACT_TUNE` 兩行 8 格，1 = 完全跟曲線。某一章單獨凸咗／凹咗先郁呢度。

⚠ `TIER.gym.hp0/hp1` 係**成隊道館主嘅總血量**，唔係單隻。單隻血由遊戲自己
除返嗰章帶幾多隻（前半 2 隻、後半 3 隻），所以「帶多咗一隻」唔會再喺
條曲線度整個凹位出嚟。魔鬼難度全程 3 隻，多出嗰隻係實打實多一隻嘅血。

```bash
N=3000 node tools/sweep.mjs '[
  {"curve":{"gym":{"hp1":1000}}},
  {"actTune":{"hp":[0.92,1,1.08,1.30,1.12,1.06,1,0.94]}}
]'
```

量魔鬼要開埋 `DIFF=1`：

```bash
DIFF=1 N=6000 node tools/sweep.mjs '[{"diff1":{"hp":[0.97,0.95,0.93,1.02,1.12,1.16,1.20,1.22]}}]'
```

搵到啱嘅組合之後，改返 `index.html` 入面 `TIER` 嘅端點同 `ACT_TUNE`，
再跑 `measure.mjs` 確認。

## 樣本數要跑幾多

**跑 500 局同跑 1400 局，用嘅 AI usage 一模一樣**（輸出都係同一舊細細嘅 JSON），
分別只係電腦行耐啲。而細樣本雜訊大，反而要多試幾轉先調得準 —— 嗰啲來回先真係燒 usage。

| 局數 | 時間 | 第 8 章樣本 | 誤差 |
|---|---|---|---|
| 1500 | ~60s | ~30 | ±18% |
| 3000 | ~115s | ~60 | ±13% |
| 6000 | ~250s | ~120 | ±9% |

八章制之後尾章嘅樣本數細好多（要連過七關先行到），所以**建議用 3000 起跳，
定案前跑一次 6000**。留意第 6-8 章數字跳 ±10 點係正常，睇趨勢唔好睇單次。

## 目前目標

目標係一個**範圍**，唔係一個點 —— 後面幾章嘅樣本數細（多數局數行唔到咁遠），
量到嘅數字本身就會跳 ±10，追死一個數字係追緊雜訊。

| | 第 1-2 館 | 第 3-5 館 | 第 6-8 館 | 四天王 |
|---|---|---|---|---|
| 困難 | 55-70% | 45-60% | 40-55% | ≤50% |
| 魔鬼 | 35-50% | 25-40% | 20-35% | ≤50% |
| 遺物 | 每章 1-2 件，第 4-5 章上限 8 件封頂 | | | |

⚠ 八章嘅目標比舊嗰個四章版**鬆好多**，唔係抄舊數字。因為要連過八關：
每章 45% 嘅話，八章全通只係 0.45⁸ ≈ 0.17%（600 局先有一局）；
每章 55% 先大約 0.8%，同舊嗰個四章版差唔多。

「四天王」＝ 打低四個道館主嘅局數入面，有幾多完成 4 連戰 + 冠軍。
呢段冇篝火冇商店，每場之間淨係回 15% HP，係一場消耗戰 ——
唯一嘅補給就係開戰前用金幣買（`E4_HEAL_COST`，價錢每用一次升一級）。

實測 16%（困難）／ 29%（魔鬼），入到 ≤50% 嘅範圍。
⚠ **呢個數字樣本天生極細**：八章制之下，跑 6000 局先得 ~55 局行到四天王
（誤差 ±13），跳十幾點都可能只係雜訊，唔好見到跌就即刻加返上去。
要再郁嘅話，旋鈕有 `E4_HEAL`、`E4_HEAL_COST`、同 `TIER.e4` / `TIER.champ`
（呢兩個 tier 標咗 `flat:true`，**唔食 `ACT_TUNE`** —— 佢哋唔屬於任何一章）。

## 調數值嗰陣要記住三件事

**一、郁一章會連帶影響之後嗰幾章。** 前面難咗，行得到後面嘅隊伍本身就強啲，
所以後面反而會顯得易咗。試過第 2 章由 46% 拉落 36%，第 4 章就自己彈上 48%。
要一次過睇齊八個數，唔好逐章追 —— 八章制呢個效應仲明顯，
第 4 章嘅 `ACT_TUNE` 由 1.10 加到 1.26，第 7-8 章自己由 47/41 升到 47/45。

**二、對倍率極度敏感，尤其係傷害。** 行到後面嘅係最強嗰幾 %，人數本身好薄，
加少少就冧一大片。實測（魔鬼第 1 章，6000 局，樣本足）：

| 改乜 | 通關率 |
|---|---|
| `hp` 0.93 / `dmg` 0.95（基準） | 50-52% |
| `hp` 0.95 | 42% |
| `dmg` 0.96（**淨係加 0.01**） | 35% |

**傷害嘅級距係血量嘅兩倍狠**，因為敵人一擊夠唔夠打死你係一個「過／唔過」嘅門檻。
調嘅時候血量一次行 0.02-0.05、傷害一次行 0.01-0.02，同埋兩樣分開試。

**三、跑幾多局係完全唔影響 AI usage。** 跑 3000 局同跑 8000 局，返嚟都係同一舊
細細嘅 JSON，分別淨係部電腦行耐幾十秒。所以**一次 sweep 塞多幾組設定去試**，
唔好一次試兩三組 —— 局數細、組數少先真係燒 usage（因為要多試幾轉）。

## ⏸ 未修：v41（免費換人 + 道具袋）令困難後半鬆咗

（厲害傷藥／復活藥丸／技能升級器，寶箱同商店拎到）。兩樣都係設計上要求嘅
「加強續戰力」，所以通關率升係預期之內，但**升幅比估計大**。

3000 局・困難（同一份 `ACT_TUNE`，淨係差呢兩個功能）：

| 章節 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 四天王 |
|---|---|---|---|---|---|---|---|---|---|
| v40（之前） | 68 | 66 | 57 | 54 | 57 | 47 | 55 | 40 | 25% |
| v41（而家） | 69 | 68 | 59 | 59 | **69** | **63** | **63** | **62** | 48% |
| 目標 | 55-70 | 55-70 | 45-60 | 45-60 | 45-60 | 40-55 | 40-55 | 40-55 | ≤50 |

頭四章基本冇郁（±1-5，喺雜訊入面），**第 5-8 章一齊高咗 12-22 點，出咗 band**。
原因好直接：後半館主帶 3 隻 = 每場多兩次免費換人，而道具袋等於多咗
「幾時回血」呢個資源。四天王 25%→48%（樣本 n=84），仲喺 ≤50 入面。

魔鬼冇乜郁（45/44/29/40/35/25 → 47/44/33/42/42/28），升幅喺雜訊範圍，
第 7-8 章樣本得 n=10 / n=2，睇唔到。

**要收返嘅話唯一啱使嘅旋鈕係 `ACT_TUNE.hp` 第 5-8 格**（而家 1.12 / 1.14 / 1.00 / 0.92）。
唔好郁 `dmg`（惡兩倍），亦都唔好郁 `TIER` 曲線（會連頭四章一齊拉低）。
候選數值同實測見下面 git log；未套用，因為「後半鬆咗」係咪問題係設計決定，
唔係 bug。

## ⏸ 半修：魔鬼後半反而易過困難

實測魔鬼係 **52 / 39 / 29 / 39 / 70 / 57 / 64 / 47**（6000 局）。
頭四章入到目標，**第 5-8 章仲係鬆**（目標 20-35%）。

原因：魔鬼嘅難度嚟自「館主全程帶 3 隻」，但呢個優勢淨係喺第 1-4 章存在
（困難嗰陣先得 2 隻）；第 5 章起困難一樣係 3 隻。而魔鬼為咗頂住頭幾章
嗰個重量，逐隻敵人係調弱咗嘅，呢個折扣一路帶到最後。

階段 3 收咗第 5 章起嗰段折扣（`DIFFS[1].hp/dmg` 而家係 8 格陣列），
後半由 81/68/63/55 改善到 70/57/64/47。但**再加倍率冇用**：

| 第 5-8 章 `hp` | 結果（第 5-8 章） |
|---|---|
| 0.93（舊，成局同一個數） | 81 / 68 / 63 / 55 |
| 1.00 → 1.06 | 68 / 61 / 65 / 27 |
| 1.04 → 1.10 | 64 / 51 / 67 / 23 |
| 1.00 → 1.06，`dmg` 一齊收 | 65 / 61 / 49 / 40 ← 而家用緊 |

加 10% 血基本上冇郁到。行到第 5 章嘅魔鬼局得大約 **2%**（6000 局淨返 ~140 局），
嗰批係最強嗰幾隊 —— 呢個係**倖存者效應，唔係數值唔夠大**。
真係要修就唔係加倍率，係要改魔鬼後半嘅結構（例如館主帶第 4 隻）。
**擺住先，因為冇乜人打魔鬼。**

⚠ 順帶量到：魔鬼第 1 章 `dmg` 由 0.95 加到 **0.96**（0.01！）通關率由 50% 跌到 35%；
`hp` 由 0.93 加到 0.95 由 50% 跌到 42%。**傷害比血量惡兩倍**，要分開調。

## 加新嘅地圖節點圖示

手機上載出嚟嘅係 JPEG，「透明背景」其實係被畫成灰白棋盤格燒死咗入去，
要還原返真正嘅 alpha。`pixicon.py` 幫你搞掂：

```
python3 tools/pixicon.py 圖片.jpeg --name rest --preview /tmp/p.png
```

`--name` 係 `index.html` 入面 `NODE_IMG` 嘅 key：
`mob` `elite` `rest` `shop` `chest` `unknown` `boss` `lock`。
腳本會 print 一行 `rest:'data:image/png;base64,...',`，抄入 `NODE_IMG` 就得；
`NODE_IMG` 冇嘅 key 會自動用返 `NODE_ICON` 嗰個 emoji，所以可以逐個逐個換。
記得開 `--preview` 用肉眼核對一次（預覽用返節點嘅深藍底色）。

圖示規格：1024×1024、透明底、一個檔一個圖示、主體用淺色、粗描邊、
**要有一圈完整嘅深色描邊包住**（腳本靠佢分開圖示同背景光暈）。
